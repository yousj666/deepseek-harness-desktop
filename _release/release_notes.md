## DeepSeek Harness Desktop v1.0.0

自己打包的 DeepSeek Harness 桌面客户端：WebView2 独立窗口，内置 Node 运行时与扩展商店，不依赖任何第三方桌面板。

### 功能
- 独立窗口聊天，界面与网页版完全一致，数据共用 ~/.dsh
- 扩展商店：1142+ 个 dsh 插件，可搜索、一键安装
- 内置 Node 运行时，无需安装 Node.js
- 高 DPI 适配；流体/粒子背景动画不受系统「减少动态效果」影响
- 标准安装向导（选路径 → 安装 → 勾选启动 + 桌面快捷方式）

### 文件
- **DeepSeek.Harness.Desktop-Setup.exe**：安装向导版（推荐）
- **DeepSeek.Harness.Desktop-Portable.zip**：绿色版，解压即用

### 使用
双击安装包 → 安装向导 → 完成页勾选「启动」。数据目录 ~/.dsh，与网页版共用。
